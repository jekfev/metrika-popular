Most read posts by Yandex.Metrika page views: site-wide or per category. Shortcode and widget.

== Description ==
Uses the Yandex.Metrika Stat API (refreshed by WP-Cron) instead of a own view counter. Shortcode `[metrika_popular]` and a widget. On a single post it shows the most read posts of its category.

== Installation ==
1. Upload the plugin and activate it.
2. Settings → Metrika Popular: counter ID and OAuth token (metrika:read).
3. Click "Refresh now" and add `[metrika_popular]`.
